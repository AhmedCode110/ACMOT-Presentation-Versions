# AC-MOT — Short 20-minute department presentation (v50)

This version is a short supervisor-facing talk. It keeps the full project story in 28 main slides:
the problem, baseline, AC-MOT method, SCI cues, VisDrone setup, ablation, pre-Optuna screening,
temporal screening, V1, V2, paired bootstrap, zero-tuning UAVDT, U2MOT transfer, and conclusion.

It is copied from v49. Older versions were not changed. The pictures, videos, charts, data files,
navigation, explanation pages, and speaker notes remain in the folder. The HTML deck is designed for
about 20 minutes with roughly 40–50 seconds per main slide.

All reported results keep their original split and protocol labels. AC-MOT results use the custom
class-agnostic AC-MOT evaluation protocol, not official VisDrone leaderboard results.
