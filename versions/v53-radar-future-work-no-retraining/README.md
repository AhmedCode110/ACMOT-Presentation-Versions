# AC-MOT — Radar future work and no-retraining contribution (v53)

This version adds radar-assisted tracking as a future direction: combine radar position and speed
with image detections to help keep object IDs during occlusion, blur, and camera motion.

It removes the old density-gated input-size item. The contributions slide now states that AC-MOT
needs no retraining and no new training data. The final slide lists Ahmed Gouda Ismail, Dr. Tarek
Ahmed Mahmoud, and Dr. Mohamed S. Mohamed.
