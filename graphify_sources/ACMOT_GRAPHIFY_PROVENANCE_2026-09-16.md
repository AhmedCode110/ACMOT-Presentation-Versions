# AC-MOT Graphify Provenance

This directory is a copy-only evidence bundle for the AC-MOT project.

## Included sources

- `acmot_shared_final_2026-09-16/`: downloaded from the Google Drive folder `defensible_acmot_3workers` (folder ID `1RRjzBy1Q_K4415A1x4FCD7B4xb60QYBs`).
- `acmot_frozen_v1_implementation_2026-09-16/`: copied from the local frozen V1 implementation snapshot dated `2026-09-12`.
- The presentation repository remains the main Graphify root and is merged with both source bundles.

## Inclusion rule

Included files are completed result artifacts, frozen configurations, protocols, full sweeps, aggregate reports, and reproducibility files that support a reported result.

Excluded files are smoke tests, temporary worker markers, unfinished or empty runs, and individual outputs that do not add evidence beyond the complete aggregate sweep. The 25 temporal JSON outputs are retained because they are completed per-configuration results for the full temporal grid.

## Drive provenance

The selected Drive files were downloaded without changing or deleting anything in Drive. Their original Drive file IDs and links are recorded in the acquisition manifest in this folder.

## Scientific use

Use the frozen V1 configuration, frozen implementation, and final test artifacts as the authority for V1 numbers. Keep validation, search, ablation, and held-out test results as separate evidence families. Do not treat smoke files or illustrative presentation examples as experiment results.
