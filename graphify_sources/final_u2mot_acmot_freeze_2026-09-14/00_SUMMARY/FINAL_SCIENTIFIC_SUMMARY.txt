======================================

Freeze date:
2026-09-14


PROJECT PURPOSE
---------------

This package contains the complete controlled
U2MOT + AC-MOT transfer experiment.

The objective was to evaluate whether AC-MOT,
originally developed using a lightweight
YOLOv8n + ByteTrack pipeline, could transfer
to a stronger published MOT framework while
keeping the published detector/tracker system
fixed.

FINAL INTERPRETATION
--------------------

The frozen held-out experiment does NOT show
MOTA superiority over reproduced U2MOT.

Instead, AC-MOT shifts the operating point:

- MOTA approximately preserved
- IDF1 approximately preserved
- ID switches reduced
- false positives reduced
- false negatives increased

This result is retained exactly as obtained.
No test-dev tuning was performed after observing
the final result.
